## BBCode · Resource-Update Post

```bbcode
[CENTER]
[SIZE=6][B][COLOR=#22c55e]JExVote — Reward-Feedback Update[/COLOR][/B][/SIZE]
[SIZE=3][I]No more chat walls. No more "check your rewards".[/I][/SIZE]
[/CENTER]

[HR][/HR]

[SIZE=5][B][COLOR=#22c55e]What changed[/COLOR][/B][/SIZE]

[LIST]
[*][B]Jackpot names the actual prize.[/B] The Vote-Jackpot broadcast used
to say "Fortune smiles on you - check your rewards!" and leave the player
guessing which of the possible drops actually landed. It now quotes the
winning reward's description inline:
[INDENT][I]"Fortune smiles on you - you won Rank Voucher Novize (7d)!"[/I][/INDENT]
Works the same in German ("Das Glück ist dir hold - du hast … gewonnen").

[*][B]Offline votes deliver one clean summary.[/B] Logging in after
missing votes used to spam one chat line per reward with a preamble.
The new join message consolidates the whole batch:

[INDENT][CODE]
[Vote] ✔ You voted offline 3 times, you got the following reward(s):
 · Rank Voucher Novize (7d)
 · 500 Crystals
 · Antike Truhe x2
[/CODE][/INDENT]

Identical rewards fold with an [B]xN[/B] suffix so a party of five doesn't
turn into five identical lines. If every grant failed you get a single
fallback "your N vote(s) were processed" line instead of nothing.
[/LIST]

[SIZE=5][B][COLOR=#22c55e]Compatibility[/COLOR][/B][/SIZE]

[LIST]
[*]No config migration - existing per-entry [B]announce[/B] keys keep
working. Keys that don't reference [B]{reward}[/B] simply render without
the placeholder.
[*]Removed i18n keys: [B]vote.delivered.header[/B], [B]vote.delivered.entry[/B],
[B]vote.delivered.entry_multiple[/B] (unused after the join path
consolidation).
[*]New i18n keys: [B]vote.offline-summary[/B], [B]vote.offline-summary-empty[/B]
(EN, DE, CS, SK parity).
[*]Paper 1.21+, Java 21, NuVotifier / Votifier, JExEconomy or Vault - as
before.
[/LIST]

[CENTER]
[SIZE=3][B]Update, restart the server, done.[/B][/SIZE]
[/CENTER]
```

## Discord · #announcements Post

```
:myth_event: **JExVote · Reward-Feedback Update**

Zwei Kern-Verbesserungen im Vote-Flow:

› **Jackpot sagt jetzt den Preis** — statt "sieh in deine Belohnungen!"
  hörst du direkt was du gewonnen hast:
  _"Das Glück ist dir hold — du hast **Rang-Voucher Novize (7 Tage)** gewonnen!"_

› **Offline-Votes als eine saubere Message** — kein Chat-Wall mehr beim
  Login. Statt fünf einzelnen Zeilen pro Reward:
  ```
  ✔ Du hast 3× offline gevotet, du hast folgende Belohnung(en) erhalten:
   · Rang-Voucher Novize (7 Tage)
   · 500 Kristalle
   · Antike Truhe x2
  ```
  Identische Rewards werden gefaltet (`x2`), leere Grants haben einen
  eigenen Fallback.

**Rebuild + Restart** — keine Config-Migration nötig. Alte Configs die
kein `{reward}` verwenden funktionieren weiter clean.
```
